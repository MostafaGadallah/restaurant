# منيو سفيان

موقع ثابت مستقل. افتح index.html مباشرة، أو شغّل خادم ملفات ثابتة من هذا المجلد.

- الأصناف والأسعار من صورتين منشورتين على صفحة المطعم (أرقام التواصل + المنيو).
- الاسم الظاهر: سفيان / SOFIAN GOOD PIZZA، والشعار: لو جعان كلم سفيان.
- أرقام التواصل الستة الظاهرة في الصورة: 01033043106، 01222872426، 01200481691، 01030983589، 01556986819، 01102362089.
- العمود الأول من المنيو (شكن رانش، موزاريلا، سيفود...) ظهر بدون عنوان مقروء في الصورة؛ سُمي «البيتزا» استنادًا إلى سياق الصفحة، ويحتاج تأكيد صاحب المطعم.
- صنف «الاكيل» في الطواجن وصفه المطبوع: تركي مدخن + شيش + مشروم + بسطرمه.
- لا يوجد عنوان محل ظاهر في الصورتين، لذلك لم يُضف عنوان.
- لا توجد خدمة دفع أو إرسال طلب تلقائي؛ روابط الاتصال وواتساب فقط.
- menu.json نسخة بيانات للمراجعة. HTML ثابت ولا يحتاج JavaScript أو بناء.
